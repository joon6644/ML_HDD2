## 1. 서론

- [문제 및 필요성] HDD가 여전히 대규모 저장 인프라에서 중요하다
- [어려웠던 점] 하지만 HDD의 고장은 다양한 상태 변화가 복합적으로 나타나기 때문에 사전에 정확하게 예측하기 어렵다.
- [본 연구의 접근] 이러한 문제를 해결하기 위해 SMART 데이터를 활용한 AI 기반 고장 예측 모델을 제안하고, 낮은 오탐률에서의 고장 탐지 성능을 중심으로 평가한다.
- [전개 예고] 연구 개요 소개

## 2. 선행 연구

### 2.1 인공지능 기반 고장 예측

### 2.2 HDD 고장 예측

## 3. 연구 방법

### 3.1 연구 개요

- [연구 목적]
    - 본 연구는 HDD의 SMART 데이터를 기반으로 고장 여부를 사전에 예측하는 모델을 제안하고, 오탐률을 고려한 고장 탐지 성능을 평가함으로써 운영환경에서 활용 가능한 수준의 고장 탐지 성능을 확보하는 것을 목표로 한다.
- [연구 흐름도] 데이터 누수 없는게 드러나게, 임곗값이 validation 기준으로 선정된게 보이게.
- [데이터 소개] 백블레이즈 소개, hgst 선정 이유, 데이터 스펙
- [연구 방향성] 전체적인 예측 방향 및 SHAP 분석

### 3.2 데이터 전처리

- [전처리] 전처리 방법 했던거 나열
- [파생변수 소개] 파생변수 1차차분절대합(asfd) 사용 이유, 수식, 의미

### 3.3 모델링

- [예측 문제 정의] 과거 데이터로 학습해서 미래 고장 여부를 예측하는 문제
    - 본 연구는 과거 SMART 관측 이력을 바탕으로 향후 일정 기간 내 HDD의 고장 여부를 예측하는 이진 분류 문제로 정의한다. 평가는 1개월을 하나의 윈도우 단위로 설정하고, 관측 가능한 마지막 3개월을 각각 독립적으로 예측한 뒤 그 결과를 하나의 모집단으로 통합하여 집계한다. 이때 윈도우 종료 시점까지 예측 기간(H일) 이내 고장 여부가 확정되지 않는 관측치, 즉 윈도우의 마지막 H일 구간은 우측 중도절단(right censoring)으로 간주하여 표본에서 제외한다. 월 단위 평가 윈도우는 RODMAN[?]이 채택한 방식과 같은 형태이며, 예측 기간 H는 SMARTer[?], LightGBM+CID[?], Model update[?]가 공통으로 사용한 10일을 따른다.
- [데이터 분할]
    - 본 연구는 시간축 기준 forward chaining 방식으로 데이터를 분할하였다. 전체 관측 기간 중 마지막 3개월을 테스트셋으로, 그 직전 1개월을 검증셋으로, 나머지 전 기간을 훈련셋으로 사용한다. 모델은 훈련셋으로 한 차례 학습한 뒤 테스트셋의 세 달을 각각 예측하며, 검증셋은 조기 종료(early stopping) 및 임곗값 결정에만 사용한다.
- [후보 모델 선정] (rf, xgb,mlp, lstm, gru, tcn) 원본 피처만 사용, 불균형처리 금지
    - HDD의 열화가 시간에 따라 진행된다는 점을 고려하여 LSTM, GRU, TCN과 같은 시계열 모델과 Random Forest, XGBoost와 같은 트리 기반 모델 및 MLP를 후보 모델로 선정하였다. 모든 후보 모델은 원본 SMART 피처를 입력으로 사용하였으며, 모델 간 비교를 위해 별도의 불균형 데이터 처리 기법은 적용하지 않았다.

### 4.1 후보 모델 비교 및 제안 모델 선정

| Model | Recall | FAR | ROC-AUC |
| --- | --- | --- | --- |
| RandomForest | 0.660 | 1.66 % | 0.965 |
| XGBoost | 0.638 | 1.31 % | 0.960 |
| LSTM | 0.596 | 1.25 % | 0.941 |
| TCN | 0.596 | 1.22 % | 0.969 |
| MLP | 0.574 | 1.14 % | 0.960 |
| CNN1D | 0.574 | 1.22 % | 0.958 |
| GRU | 0.511 | 1.14 % | 0.936 |
| LightGBM | 0.234 | 0.92 % | 0.951 |
- (rf, xgb, lgbm, mlp, lstm, gru, tcn) 등 베이스라인으로 비교했을 때 어떤 모델이 압도적으로 좋게 나오진 않았지만 xgb가 균형있게 상위권이었음
- 시퀀스 모델(LSTM, GRU, TCN)이 트리 기반 모델을 넘어서지 못한 것은 시간축 정보가 무의미해서가 아니라, 고장 신호가 원시 관측 시퀀스의 형태보다 누적된 변동량이라는 요약된 형태로 더 잘 드러나기 때문으로 해석된다.
