## 3. 연구 방법

### 3.1 연구 개요

- 연구 목적
    - 본 연구는 HDD의 SMART 데이터를 기반으로 고장 여부를 사전에 예측하는 모델을 제안하고, 오탐률을 고려한 고장 탐지 성능을 평가함으로써 운영환경에서 활용 가능한 수준의 고장 탐지 성능을 확보하는 것을 목표로 한다.
- 연구 흐름도
- 데이터 소개
- 예측 / SHAP 분석

### 3.2 데이터 전처리

- 우리 했던거 나열 + 파생변수

### 3.3 모델링

- 예측 문제 정의: 과거 데이터로 학습해서 미래 고장 여부를 예측하는 문제
    - 본 연구는 과거 SMART 관측 이력을 바탕으로 향후 일정 기간 내 HDD의 고장 여부를 예측하는 이진 분류 문제로 정의한다. 평가는 1개월을 하나의 윈도우 단위로 설정하고, 관측 가능한 마지막 3개월을 각각 독립적으로 예측한 뒤 그 결과를 하나의 모집단으로 통합하여 집계한다. 이때 윈도우 종료 시점까지 예측 기간(H일) 이내 고장 여부가 확정되지 않는 관측치, 즉 윈도우의 마지막 H일 구간은 우측 중도절단(right censoring)으로 간주하여 표본에서 제외한다. 월 단위 평가 윈도우는 RODMAN[?]이 채택한 방식과 같은 형태이며, 예측 기간 H는 SMARTer[?], LightGBM+CID[?], Model update[?]가 공통으로 사용한 10일을 따른다.
- 데이터 분할
    - 본 연구는 시간축 기준 forward chaining 방식으로 데이터를 분할하였다. 전체 관측 기간 중 마지막 3개월을 테스트셋으로, 그 직전 1개월을 검증셋으로, 나머지 전 기간을 훈련셋으로 사용한다. 모델은 훈련셋으로 한 차례 학습한 뒤 테스트셋의 세 달을 각각 예측하며, 검증셋은 조기 종료(early stopping) 및 임곗값 결정에만 사용한다.
- 후보 모델 선정 (rf, xgb,mlp, lstm, gru, tcn) 원본 피처만 사용, 불균형처리 금지
    - 본 연구는 HDD의 열화가 시간 흐름에 따라 누적되는 순차적 과정이라는 가정 하에, LSTM, GRU, TCN과 같은 시계열 기반 모델을 트리 기반 모델과 함께 비교하였다. 실험 결과, 시계열 모델은 트리 기반 모델과 비슷하거나 오히려 낮은 예측 성능을 보였다. 본 연구에서 사용한 SMART 속성은 정형 데이터이며, 시간적 순서 정보보다 각 시점의 속성값 자체가 고장 예측에 더 직접적인 신호로 작용했기 때문으로 판단된다. 실제로 RandomForest, XGBoost 등 트리 기반 모델이 전반적으로 우수한 성능을 나타냈으며, 반면 동일한 부스팅 계열임에도 LightGBM은 상대적으로 낮은 성능을 기록하였다. 이러한 결과를 종합하여 본 연구는 XGBoost를 예측 모델로 채택한다.
