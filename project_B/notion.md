- HDD가 여전히 대규모 저장 인프라에서 중요하다
- 그래서 HDD 고장 예측이 운영 측면에서 중요하다
- 그런데 HDD 고장 예측은 생각보다 어렵다 (클래스 불균형, 전통적 방법의 한계)
- 연구 개요 소개

## 3. 연구 방법

### 3.1 연구 개요

- 연구 목적
    - 본 연구는 HDD의 SMART 데이터를 기반으로 고장 여부를 사전에 예측하는 모델을 제안하고, 오탐률을 고려한 고장 탐지 성능을 평가함으로써 운영환경에서 활용 가능한 수준의 고장 탐지 성능을 확보하는 것을 목표로 한다.
- 연구 흐름도
- 데이터 소개
- 예측 방법 / SHAP 분석

### 3.2 데이터 전처리

- 우리 했던거 나열 + 파생변수

### 3.3 모델링

- 예측 문제 정의: 과거 데이터로 학습해서 미래 고장 여부를 예측하는 문제
- 데이터 분할
- 후보 모델 선정 (rf, xgb, lgbm, mlp)
- 불균형 데이터 처리
- 하이퍼파라미터튜닝
