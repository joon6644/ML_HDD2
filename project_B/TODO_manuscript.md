## 남은 수정 (2건)

- [ ] **1장 `특히 오탐률 5% 이하 구간의 부분 AUC를`** — `부분 AUC(partial AUC, pAUC)`로 병기.
  `pAUC`가 바로 다음 문단(기여 둘째)부터 쓰이는데 논문 어디에도 풀이가 없다. 국·영 초록도 동일

- [ ] **3.3 `모든 모델은 동일한 입력과 실험 조건 및`** — 주어·서술어 호응.
  `모든 모델에 동일한 입력과 실험 조건 및 하이퍼파라미터 탐색을 적용하여 비교한다`

## 넣을지 미정 (전부 선택)

- [ ] 3.1 `하이퍼파라미터 탐색을 적용한 뒤` → `동일한 하이퍼파라미터 탐색` (표 1 공정성 주장을 개요에도)
- [ ] 3.1 `예측 시점으로부터 10일` → `각 관측 시점으로부터` (`예측 시점`은 3.3에서 정의됨)
- [ ] 3.2 `min_history_days: 30` — 관측 시작 직후 30일 제외가 본문에 없음
- [ ] 3.4 `저오탐률 구간의 성능과 함께` → `구간 전체의 성능` (뒤의 `특정 오탐률에서의 탐지 성능`과 대구)
- [ ] 4.3 시점 축 `이는 모델의 예측 근거가 입력 윈도우의 양 끝에…` — 앞 문장의 68.9%와 중복
- [ ] 5장 한계 `특정 HDD 모델` 앞에 `하나의 운영 환경에서 수집된`
- [ ] 머리말 여섯 줄(`한국정보기술학회 게재…` ~ `초안`) 투고본에서 삭제
